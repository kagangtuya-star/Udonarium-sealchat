# Udonarium @ HKTRPG — 2026/09/08–10 更新

## 圖片庫・曲庫刪除

- 圖片庫選取後可刪除：從**本房間**與**目前連線中的其他玩家**一併移除，下次儲存房間時不再包含。
- 刪除後**不會被 P2P 再傳回來**；角色／地圖／卡牌若仍引用會變空白。**重新匯入同一檔**可還原。
- 曲庫：多選 **Delete**，或右鍵刪除單首，規則相同。

## ZIP／資料夾還原

- 打包的音訊／影片與卡圖一樣用**雜湊檔名**（`hash.ext`）還原，讀取 ZIP／資料夾備份後較不易缺檔。

## 角色卡

- **勾選欄**：未勾選時仍顯示選項文字（Token 懸停、角色卡、倉庫）。`開|關` 成對時，未勾顯示關側。
- **編輯 MODE** 更緊湊：選項／筆記／網址不再撐大卡片；「新增項目」在「切換編輯」左側。
- **筆記欄**可垂直拉高，並記住高度。
- **圖片庫**關閉文字選取，方便框選圖片。
