# Udonarium @ HKTRPG — 2026/09/03–07 更新

## Print & Play・牌面匯入

- PDF **Print & Play** 可指定頁面範圍、自動裁切後建成牌堆。
- 裁切預覽支援縮放／平移／磁吸邊；手動邊距與自動偵測可並存，不會因偵測亂改牌面寬高。

## 街景匯入（Open3Dhk／PLATEAU）

- 匯入可當背景工作跑，並顯示進度 HUD；支援樓地板邊緣裁切。
- 香港比例與 bake 群組選擇改善；GSI 航照地面對齊；薄烘焙縮圖與中途重試較穩。

## 房間密碼・檔案・手牌

- 建立／開啟房間後保留玩家**角色密碼**；離房或部分寫入不再清掉資料夾備份密鑰。
- 入房早期顯示 **FILES** 進度、地圖圖優先；取消選圖不再清空 Token 圖像。
- 鎖定的牌堆／單卡不可作為合併目標；卡預覽文字、TTS 表預覽、圖片筆記貼底改善。

## 快捷鍵

- 右鍵選單標示 **Ctrl＋C／X／V**（暫存 Token：**Ctrl＋Shift＋V**）。
- 骰子／硬幣改按 **R** 重擲；**F** 仍翻單卡／整疊牌堆。
